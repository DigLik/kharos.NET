# Ролики Shorts

Вертикальные ролики 1080×1920, 60 к/с, 40–55 с: кадры игры из headless Chrome, нейросетевая озвучка, субтитры шрифтом
игры, музыкальная подложка на аккордах меню. Каждый ролик — папка в `videos/` со всеми исходниками на каждом языке;
там же журнал роликов (`videos/README.md`) — с него начинать.

## Устройство

```
tools/shorts/
  videos/README.md         журнал: что снято, статусы, как завести новый ролик
  videos/NN-тема/
    README.md              замысел, что проверено, грабли этого ролика
    record.sh              съёмка клипов
    scenes/                действия в игре для планов с интерфейсом (если есть)
    ru/ en/                lines.txt — реплики, caps.json — подписи и обложка,
                           plan.json — голос, план монтажа, кадр обложки; meta.md — название и описание
  rec.ts make.sh build.py  съёмка, сборка одной командой, монтаж
  tts.sh caps.ts music.ts  озвучка, подписи, музыка
  hooks.patch              временные хуки съёмки в игре
  open.sh cdp.ts sheet.sh cuts.sh find.js port.js seeds.ts showcase.css — подсобное
```

## Что нужно

- Chrome, ffmpeg, bun, python3.
- edge-tts: `python3 -m venv ~/.kharos-tts && ~/.kharos-tts/bin/pip install edge-tts`.
- Dev-сервер: `npx vite --port 5199 --strictPort` из корня репозитория.

Работать в отдельной рабочей папке вне репозитория, своей на каждый ролик (кадры весят гигабайты); скрипты звать
по полному пути. Готовые видео в репозиторий не кладём.

## Собрать готовый ролик

```sh
git apply tools/shorts/hooks.patch                  # хуки съёмки
mkdir -p ~/shorts/02 && cd ~/shorts/02
zsh $K/tools/shorts/videos/02-who-wins/record.sh    # клипы → clips/ (K — корень репозитория)
zsh $K/tools/shorts/make.sh $K/tools/shorts/videos/02-who-wins ru   # → ru/02-who-wins-ru.mp4 и обложка
zsh $K/tools/shorts/make.sh $K/tools/shorts/videos/02-who-wins en
cd $K && git checkout src                           # откатить хуки
```

`make.sh` делает озвучку (голос из `plan.json`), подписи, музыку (одна на папку), монтаж и обложку. Предупреждение
«short clip» — кусок плана длиннее записи: сдвинуть начало, поднять ускорение или переснять. Бои витрины после
пересъёмки кончаются в другое время — границы покажет `cuts.sh <клип>`, начала планов подогнать под них.

## Новый ролик

1. Тема и замысел — см. журнал. Строку и папку завести сразу, исходники — по образцу готового ролика.
2. **Хуки съёмки:** `hooks.patch` добавляет витрине `?zoom=` (пикселей на тайл), `?hour=` (час суток), `?orbit=`
   (радиус кружения камеры), `?a=tank:4&b=drone:10` (составы армий в сценке боя: `a` — слева, `b` — справа) и
   `window.__scene` (сим и камера), `?fog=0` (без тумана) и `window.__host(code)` — выполнить `(sim) => …` в воркере
   хоста: мир локальной игры считает воркер, `__scene.sim` во вкладке — только копия (пример — `videos/03-nuke`). Новый хук — дописать в игру с пометкой `// TEMP-SHORTS` и обновить патч:
   `git diff -- src > tools/shorts/hooks.patch`.
3. **Сценарий:** `lines.txt` — реплики `NN|текст` (в русском ударение — знак U+0301 после гласной, «Ха́рос»);
   `caps.json` — подпись на каждую реплику (строка с разметкой `<b>` — обычная подпись внизу; HTML с `<div` —
   как есть), финальная карточка `end` и обложка `cover`.
4. **Съёмка** (`record.sh`): `bun rec.ts <url> clips/<имя> <секунд> --size=720x1280 --dpr=1.5 [--css=showcase.css]
   [--warm=мс] [--lang=en-US] [--setup=модуль.ts] [--act=модуль.ts]`.
   - Сценки витрины (без интерфейса): `?scene=air|armor|battle|infantry|construction|mining|defense` с
     `--css=showcase.css`. Удачные числа: бои `zoom=40–56`, стройка 64, оборона 46, база 42; `orbit=1.5`; ночь —
     `hour=22.5`.
   - Планы с интерфейсом: модули `setup` (до записи) и `act` (во время записи) получают `c` с `click`, `move`,
     `drag`, `press(текст кнопки)`, `at(текст)`, `evaluate`, `sleep` и `t(ключ)` — строка словаря игры на языке
     съёмки. Кнопки жать через `c.press(c.t('grid.deploy'))`, тогда сцена одна на все языки. Пример —
     `videos/01-mechanics/scenes/`. Зёрна, где MCV стартует на скале, ищет `seeds.ts`.
   - Положение юнитов и зданий на экране — через сим: `find.js`, `port.js` + `__scene.camera.tileToScreen`.
   - Проверка кадров: `sheet.sh <клип>` (из рабочей папки, нужна `sheets/`) — 5 кадров в `sheets/<клип>.jpg`.
5. **Монтаж:** `plan.json` — `plan`: [клип, начало в клипе (с), ускорение, реплика, подпись], длина плана = реплика
   + 0,45 с; `cover`: клип и номер кадра для обложки. Затем `make.sh`.
6. Журнал, `meta.md`, коммит.

## Грабли

- Английская версия: `rec.ts --lang=en-US`; игра на английском открывается сразу партией — сцена, которой нужно
  главное меню, выходит через меню паузы (см. `deploy_setup.ts`). Голос — en-US-AndrewNeural.
- Патч хуков обновлять только через `git diff -- src`: без `-- src` в него попадёт он сам.
- Съёмки запускать по одной: `rec.ts` всегда берёт порт 9333, параллельные столкнутся.
- Витрина после конца боя через ~1 с затемнения начинает новый на другой карте: границы боёв в записи искать по скачку
  яркости, а запись начинается уже идущим боем (`warm`) — короткий бой брать второй, а не первый.
- Исход дуэли проверять прогоном симуляции до съёмки (как в `tools/harness/combat.ts`): таблица противовесов в
  `docs/gameplay.md` сводная, на конкретных числах она может не сработать (40 солдат проигрывают 6 лансерам).
- Headless Chrome не даёт окно уже 500 пикселей: узкие размеры — только эмуляцией (`VP=390x844x2 bun cdp.ts …`).
- Масштаб камеры — в CSS-пикселях; при плотности 1,5 всё мельче, чем кажется по числу.
- Новая игра без зерна — случайная карта: для повторяемых планов задавать зерно в форме.
- Чтобы выйти из сохраняемой игры, в меню паузы кнопка «Сохранить и выйти», а не «Выйти в главное меню».
- Голос macOS (`say`) не годится — только нейросетевой.
- Кадры без звука игры: витрина звук не играет, музыка — своя подложка.
