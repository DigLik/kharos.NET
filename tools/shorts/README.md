# Ролики Shorts

Вертикальные ролики 1080×1920, 60 к/с, ~55 с: кадры игры из headless Chrome, нейросетевая озвучка, субтитры шрифтом
игры, музыкальная подложка на аккордах меню. Первый ролик — механики игры (2026-10-14), его сценарий — `lines.txt`,
`caps.json`, план монтажа — `PLAN` в `build.py`.

## Что нужно

- Chrome, ffmpeg, bun, python3.
- edge-tts: `python3 -m venv ~/.kharos-tts && ~/.kharos-tts/bin/pip install edge-tts`.
- Dev-сервер: `npx vite --port 5199 --strictPort` из корня репозитория.

Работать в отдельной папке вне репозитория (кадры весят гигабайты): скопировать туда `caps.json`, `lines.txt`,
`build.py`, `showcase.css` и звать остальные скрипты по пути `tools/shorts/…`.

## Порядок

1. **Хуки съёмки:** `git apply tools/shorts/hooks.patch` (в конце — `git checkout src/game/game.ts src/ui/Showcase.tsx`).
   Патч добавляет витрине параметры `?zoom=` (пикселей на тайл), `?hour=` (час суток), `?orbit=` (радиус кружения
   камеры), `?a=tank:4&b=drone:10` (составы армий в сценке боя: `a` — слева, `b` — справа) и `window.__scene` (сим и камера) для управления из страницы. Если патч не встаёт — повторить руками по
   его тексту.
2. **Сценарий:** `lines.txt` — реплики `NN|текст` (ударение — знак U+0301 после гласной, «Ха́рос»), `caps.json` —
   короткие подписи (HTML) на каждую реплику и финальная карточка `end`.
3. **Озвучка:** `tools/shorts/tts.sh lines.txt` → `vo/NN.aiff` с длительностями. Длина плана = реплика + 0,45 с.
4. **Съёмка:** `bun tools/shorts/rec.ts <url> clips/<имя> <секунд> --size=720x1280 --dpr=1.5 [--css=showcase.css]
   [--warm=мс] [--setup=модуль.ts] [--act=модуль.ts]`. Сам жмёт «Продолжить» на загрузке.
   - Сценки витрины (без интерфейса): `?scene=air|armor|battle|infantry|construction|mining|defense` с `--css=showcase.css`.
     Удачные числа: бои `zoom=56`, стройка 64, оборона 46, база 42; `orbit=1.5`; ночь — `hour=22.5`.
   - Планы с интерфейсом: модули `setup` (до записи) и `act` (во время записи) получают `c` с `click`, `move`,
     `drag`, `press(текст кнопки)`, `at(текст)`, `evaluate`, `sleep`. Примеры — `scenes/`: разворот MCV (новая игра
     на зерне 14 — старт на скале; другие такие зёрна — 10, 15, 19, 20, искать `scenes/seeds.ts`), продажа на
     космопорте и окно исследований в `?sandbox`.
   - Положение юнитов и зданий на экране — через сим: `find.js`, `port.js` + `__scene.camera.tileToScreen`.
5. **Проверка кадров:** `tools/shorts/sheet.sh <имя>` (из рабочей папки) — 5 кадров клипа в `sheets/<имя>.jpg`.
6. **Субтитры:** `tools/shorts/open.sh 1080 1920 1 "http://localhost:5199/?scene=night"`, потом
   `bun tools/shorts/caps.ts` → `caps/*.png`.
7. **Музыка:** `bun tools/shorts/music.ts`, затем
   `ffmpeg -i music_raw.wav -af "aecho=0.8:0.7:120|260|430:0.35|0.25|0.18,lowpass=f=5000,loudnorm=I=-24" music.wav`.
8. **Монтаж:** поправить `PLAN` в `build.py` (клип, начало, ускорение, реплика, подпись) и `python3 build.py` →
   `kharos-short.mp4`. Предупреждение «short clip» — кусок длиннее записи: сдвинуть начало или переснять.
9. Откатить хуки (п. 1).

## Грабли

- Съёмки запускать по одной: `rec.ts` всегда берёт порт 9333, параллельные столкнутся.
- Витрина после конца боя через ~1 с затемнения начинает новый на другой карте: границы боёв в записи искать по скачку
  яркости, а запись начинается уже идущим боем (`warm`) — короткий бой брать второй, а не первый.
- Исход дуэли проверять прогоном симуляции до съёмки (как в `tools/harness/combat.ts`): таблица противовесов в
  `docs/gameplay.md` сводная, на конкретных числах она может не сработать (40 солдат проигрывают 6 лансерам).

- Headless Chrome не даёт окно уже 500 пикселей: узкие размеры — только эмуляцией (`VP=390x844x2 bun cdp.ts …`).
- Масштаб камеры — в CSS-пикселях; при плотности 1,5 всё мельче, чем кажется по числу.
- Новая игра без зерна — случайная карта: для повторяемых планов задавать зерно в форме.
- Чтобы выйти из сохраняемой игры, в меню паузы кнопка «Сохранить и выйти», а не «Выйти в главное меню».
- Голос macOS (`say`) не годится — только нейросетевой.
- Кадры без звука игры: витрина звук не играет, музыка — своя подложка.
