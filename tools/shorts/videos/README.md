`../README.md`. Готовые видео в репозиторий не кладём: они собираются из исходников.

Обновлять таблицу при каждом новом ролике и после публикации.

## Новый ролик

1. Тема — то, чего ещё нет в таблице и в заметках роликов. План — 2–3 ролика в неделю.
2. Папка `NN-тема/`: `README.md` (замысел, что проверено, грабли), `record.sh`, и на каждый язык `lines.txt`,
   `caps.json`, `plan.json`, `meta.md` — образец любой из готовых.
3. Сдаётся комплектом: видео, обложка 1080×1920, название с двумя запасными, описание со ссылками и хештегами.
4. Строка в таблице выше и коммит.
