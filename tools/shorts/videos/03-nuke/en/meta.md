# Description

A fortress with walls, turrets, a shield and an army — versus one missile silo. The whole server gets warned about the launch, regular anti-air can't touch the missile, and shields don't stop the blast: all that's left is craters. Only an interceptor saves you — it shoots the missile down mid-flight.

What would you build: the silo or the interceptor?

Every shot is real gameplay, no added effects.
