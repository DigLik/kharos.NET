Чтобы проверить файл, скачайте SHA256SUMS.txt в ту же папку и сверьте сумму:

The builds are not signed. Windows SmartScreen shows “Unknown publisher”: click More info, then Run anyway.

To verify a file, download SHA256SUMS.txt into the same folder and compare the hash:

# Linux
sha256sum -c --ignore-missing SHA256SUMS.txt
# Windows PowerShell
(Get-FileHash .\kharos-win-x64.zip -Algorithm SHA256).Hash
# compare with the matching line in SHA256SUMS.txt

Или из консоли (для arm64 замените x64 на arm64):

Or from a shell (for arm64 replace x64 with arm64):

curl -LO https://github.com/DigLik/kharos.NET/releases/latest/download/kharos-server-linux-x64.tar.gz
tar xzf kharos-server-linux-x64.tar.gz
cd kharos-server-*-linux-x64
PORT=8787 ./kharos-server

Архив распаковывается в папку kharos-server-<версия>-linux-x64. Настройки — settings.json в текущей папке (создаётся при первом запуске; другой путь — --settings или переменная SETTINGS): порт, мод, правила партии. Порт также задаётся переменной PORT. ./kharos-server --version печатает версии сборки и протокола; клиент и сервер должны быть из одного релиза.

The archive extracts to a kharos-server-<version>-linux-x64 folder. Settings are in settings.json in the current folder (created on first start; another path via --settings or the SETTINGS variable): port, mod, match rules. The port can also be set with the PORT variable. ./kharos-server --version prints the build and protocol versions; the client and server should come from the same release.
